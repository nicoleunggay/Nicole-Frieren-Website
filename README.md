# Nicole's Frieren-Inspired Personal Website

This project follows the basic structure of the teacher-provided My First Website resource:
- header
- logo
- right-side navigation
- main content sections
- footer
- separate CSS file

It has been customized with Nicole's personal information and a Frieren-inspired forest, parchment, moonlight, and gold theme.

## Open in Visual Studio Code
1. Extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html`.
4. Use Live Server if installed, or open `index.html` directly in a browser.

## Replace pictures
Replace the files inside `images/` while keeping the same filenames:
- `nicole.jpg`
- `frieren.jpg`
- `metamorphosis.jpg`

## GitHub Pages
1. Create a GitHub account or sign in.
2. Create a new repository, for example `nicole-frieren-website`.
3. Upload `index.html`, `style.css`, and the entire `images` folder.
4. Open the repository's **Settings → Pages**.
5. Under deployment, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.
7. GitHub will provide your website URL.

The exact GitHub menu wording may change, but the important requirement is that `index.html` is in the repository's root folder.
